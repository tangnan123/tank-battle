# 坦克大战 · Tank Battle

一个用**纯 HTML + CSS + JavaScript** 写的经典坦克大战（Battle City）复刻版。
**单文件、零依赖、零构建**——用浏览器打开 `index.html` 就能玩。

## 快速开始

```bash
git clone https://github.com/<你的用户名>/tank-battle.git
cd tank-battle
```

然后直接双击 `index.html`，或者拖进浏览器。

> 想在线玩？在仓库 **Settings → Pages** 里把 Source 设为 `main` 分支根目录，
> 稍等片刻后访问 `https://<你的用户名>.github.io/tank-battle/` 即可。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 开火 | `空格` / `J` / `K` |
| 暂停 | `P` 或 `Esc` |
| 重新开始 | `R` |
| 开始 / 继续 | `回车` 或点击画面 |

手机和平板会自动显示屏幕方向键与开火按钮。

## 玩法

守住屏幕底部的**老鹰基地**，消灭每关的 20 辆敌军坦克。基地被击毁或三条命耗尽即游戏结束。

### 敌军类型

| 类型 | 生命 | 速度 | 分值 | 特点 |
| --- | --- | --- | --- | --- |
| 普通 | 1 | 慢 | 100 | 灰白色，最常见的敌人 |
| 快速 | 1 | 快 | 200 | 淡蓝色，移动速度约为普通的两倍 |
| 火力 | 1 | 中 | 300 | 绿色，射速快且能同时发射两发 |
| 装甲 | 4 | 慢 | 400 | 颜色随剩余血量由绿变黄、变橙、变红，需命中四次 |

每关第 **4、11、18** 辆出场的敌军坦克会**闪烁**，击毁后会掉落道具。

### 道具

| 图标 | 名称 | 效果 |
| --- | --- | --- |
| ★ | 火力升级 | 提升主炮等级：1★ 弹速加快 → 2★ 可同时发射两发 → 3★ 可击穿钢墙 |
| ⛨ | 护盾 | 获得约 10 秒无敌时间 |
| ⏱ | 时钟 | 冻结全部敌军 8 秒 |
| ⛏ | 铲子 | 把基地周围的围墙临时变成钢墙，15 秒后还原 |
| ✹ | 手雷 | 立即摧毁场上所有敌军 |
| ♥ | 坦克 | 额外增加一条命 |

### 地形

- **砖墙**——可被子弹逐小块击碎（每格分 4 个小块，打掉哪块全看弹道）
- **钢墙**——普通子弹打不动，只有 3★ 强化弹能击穿
- **树林**——坦克和子弹都能穿过，但会遮住视野
- **河流**——坦克无法通过，子弹可以飞过
- **冰面**——坦克会打滑，松开按键后还会向前滑行一段

## 关卡

内置 5 个关卡，地图逐关变复杂，敌军配置也逐关变强（装甲坦克比例上升）。
清空当前关卡的敌军即可进入下一关，通关全部 5 关即胜利。

关卡地图是 `index.html` 里 `LEVELS` 数组中的字符串，改起来很直观：

```js
'.I.........I.',   // . 空地   # 砖墙   @ 钢墙
'.I.@@...@@.I.',   // T 树林   ~ 河流   I 冰面
'...@@...@@...',   // B 基地（必须占 2×2 格）
```

每行 13 个字符，共 13 行。敌军出生点会自动清空，不用担心摆错。

## 技术说明

- **渲染**——原生 Canvas 2D，矢量绘制（没有一张图片素材），随窗口自适应缩放并适配高分屏
- **音效**——Web Audio API 实时合成（振荡器 + 噪声），同样没有音频文件
- **坐标**——13×13 格，每格 32 CSS 像素；砖墙再细分成 16 像素的小块以便逐块破坏
- **碰撞**——子弹按每帧 4 像素分步推进，避免高速穿模
- **手感**——转向时自动对齐到半格网格，贴墙时还会微调蹭位，避免"差一点点过不去"
- **记录**——最高分存在浏览器 `localStorage` 里

## 兼容性

任何支持 Canvas 2D 和 Web Audio 的现代浏览器都可以运行（Chrome / Edge / Firefox / Safari）。
首次交互前浏览器会静音，点击或按键后音效才会启用——这是浏览器的自动播放策略，不是 bug。
